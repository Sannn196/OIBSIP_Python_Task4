 Basic Weather Application

 Description
A simple command-line Weather Application developed using Python. It fetches real-time weather information for a user-entered city using the OpenWeatherMap API.

Technologies Used
- Python
- Requests Library
- OpenWeatherMap API

Features
- Search weather information by city name.
- Display temperature in Celsius and Fahrenheit.
- Show humidity percentage.
- Display weather conditions.
- Show wind speed.
- Handle invalid city names and API errors.
- Handle internet connection errors and request timeouts.

Requirements
- Python 3.x
- Requests Library
- OpenWeatherMap API Key

Installation
Install the required library:

```bash
pip install requests
```
 How to Run
1. Install Python.
2. Install the Requests library.
3. Configure your OpenWeatherMap API key.
4. Run the Python program.
5. Enter a city name to view its weather information.

Learning Outcomes
- Understanding API integration.
- Working with JSON data.
- Using the Requests library.
- Implementing exception handling.
- Retrieving real-time weather information.
